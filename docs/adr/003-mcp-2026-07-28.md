# ADR-003: Target MCP protocol 2026-07-28

- Status: accepted
- Date: 2026-10-19
- Context: research R3; checked in M0 (rmcp 3.5.1 defines `ProtocolVersion::V_2026_07_28`)

## Decision

- Use rmcp 3.5.x and target MCP 2026-07-28, while keeping rmcp's support for older clients that
  use the `initialize` handshake (2025-11-25 and earlier).
- There are no protocol sessions in 2026-07-28. "Session" in guildsmith means the lifetime of the
  stdio server process.
- `tools/list` is deterministic and fixed for the life of the process.
- Logging goes to stderr only; the protocol's logging capability is not used.

## Consequences

Nothing in guildsmith depends on features only in 2026-07-28, so older clients keep working.
